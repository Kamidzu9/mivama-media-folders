# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Mivama Media Folders.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability. Use GitHub Private Vulnerability Reporting when it is enabled for this repository.

Include the affected plugin version, WordPress/PHP versions, reproduction conditions, impact, and any suggested mitigation if known.

Public disclosure should wait until a fix or coordinated disclosure plan is available.
